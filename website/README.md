# EmberSigh 产品网站

单文件静态站点，零构建、零依赖、零后端。双击 HTML 即可运行，也可用任意静态服务器托管。

## 最终版：index-v2.html

### 五个视图

| # | 视图 | 锚点 | 内容 |
|:-:|------|------|------|
| 1 | 理念 Vision | `#vision` | 核心主张、三条设计原则、三个使用场景 |
| 2 | 控制台 Console | `#console` | 240×240 设备屏模拟、三级状态机、HAL 实时日志 |
| 3 | 嗅觉实验室 Lab | `#lab` | 三通道香精混配、场景预设、时间轴配方、情绪预测 |
| 4 | 硬件 Hardware | `#hardware` | 接线拓扑、引脚分配表、技术规格、五条避坑笔记 |
| 5 | 开发者 Developer | `#dev` | 系统架构、技术栈、GitHub 入口、开发进度 |

支持 URL 锚点直达，例如 `index-v2.html#dev`。

### 交互能力

- **三级状态机**：`Calm`(深蓝) → `Noise!`(紫红) → `Calming`(橙色 3s 冷却) → 自动回 `Calm`
  - 「模拟拍手」自动触发完整时序
  - 三个状态药丸可手动切换
  - 冷却进度环由 `conic-gradient` 逐帧绘制
  - RMS 采用 EMA 平滑（α = 0.20，与固件一致）
- **嗅觉实验室**：点击香精瓶滴入（含 FLIP 抛物线动画）→ 实时混色 → 比例条 / 情绪预测 / 混合色卡联动
- **硬件视图**：悬停或点击引脚表行，对应 SVG 连线高亮
- **键盘导航**：`1`–`5` 切换视图，`←` `→` 在视图间移动

### 工程特性

| 特性 | 实现 |
|------|------|
| 响应式 | 1024 / 820 / 640 三级断点，三栏 → 双栏 → 单栏 |
| 字体 | 纯本地字体栈（Georgia + 宋体 + 苹方），无 Google Fonts 外链 |
| 无障碍 | `role="tablist"` / `aria-selected` / `aria-live` / `focus-visible` |
| 动效降级 | 完整支持 `prefers-reduced-motion` |
| 性能 | `visibilitychange` 与 `IntersectionObserver` 暂停不可见时的动画 |

## 本地预览

```bash
cd website
python -m http.server 8080
```

- 桌面：`http://localhost:8080/index-v2.html`
- 手机：`http://<本机局域网IP>:8080/index-v2.html`（需与电脑同一 WiFi）
