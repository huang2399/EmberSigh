# EmberSigh (听眠) - 桌面睡眠环境管家

基于 ESP32-S3-EYE 的端侧睡眠环境自适应调节设备。
不佩戴、无摄像头、纯听觉感知，主打"懂退让、不打扰"的轻量级智能睡眠体验。

## 核心功能
1. **纯听觉感知**：利用板载 ES8311 Codec 麦克风，实时提取环境音频（I2S 读取，提取左声道），计算 RMS 音量。
2. **自适应退让（开发中）**：当识别到用户翻身（音量突增）时，设备将自动降低喇叭音量、停止香氛释放。
3. **状态可视化**：当前利用板载 ST7789 LCD 屏幕显示状态（安静时显示蓝色 "Listening..."，噪音时显示红色 "Noise!"）。

## 技术栈
- **主控**：ESP32-S3-EYE (8MB PSRAM)
- **音频采集**：ES8311 Codec (I2S1, 左声道 RMS 计算)
- **显示**：ST7789 SPI LCD (240x240)
- **开发环境**：ESP-IDF v5.4.3
