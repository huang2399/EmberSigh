# EmberSigh 3D 动效演示视频（VIDEO）

本目录中的 `EmberSigh-演示视频-3D动效展示.html` 是**视频演示文件**，不是网页应用或产品原型。

- 类型：单文件 HTML 动效展示（离线可双击运行），可直接在浏览器内播放并导出 WebM 视频
- 内容：按 animos.app/editor 演示录屏复刻的 3D 卡片动效，5 段共约 23 秒
  1. 开场特写（OPENING CLOSEUPS）——每张关键图依次居中特写
  2. 卡片展开（CARD SPREAD）
  3. 竖排卡列（VERTICAL STACK）
  4. 立体翻书（BOOK FLIP）——多页绕水平轴翻动的核心效果
  5. 收尾展开（FINAL SPREAD）
- 素材：全部使用本项目 `网页版/images/` 下的产品图、设备状态屏（宁静 / 安抚 / 退让 / 睡眠）与森林 / 雨夜 / 海潮三场景图，已内嵌，无外部依赖
- 操作：空格播放/暂停；数字 1–5 跳转段落；点击进度条跳转；右上角「导出视频」录制完整 23 秒 WebM
- 文件名已明确标注「演示视频」，以区别于 `video_1/` 下的 60 秒品牌片素材
