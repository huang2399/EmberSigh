## 设计语言

最终版（`index.html`）确立的视觉体系：

- **底色**：米白珍珠（`#f8f4ed → #ece5d7` 渐变）＋ 多层暖光径向晕染
- **主色**：暖金 `#b08d57`，辅以松木绿 `#7d9471`、柑橘 `#e2a24b`、薰衣草紫 `#9d8ec7`
- **字体**：Cormorant Garamond（西文展示）+ Noto Serif SC（中文衬线）+ JetBrains Mono（数据）
- **质感**：玻璃拟态卡片、噪点纹理、漂浮光尘、顶部金色细线

## 四视图结构

1. **理念 Vision** — 核心主张「最高级的智能，是懂得退让」＋三条设计原则
2. **控制台 Console** — 240×240 设备屏模拟，三级状态机（Calm → Noise! → Calming 3s 循环），HAL 实时日志
3. **嗅觉实验室 Lab** — 三瓶香精滴入混色、场景预设、时间轴自动配方、四维情绪预测
4. **开发者 Developer** — SVG 接线拓扑（悬停联动）、引脚分配表、五条硬件避坑笔记

## 硬件前提（贯穿所有原型）

| 信号 | GPIO | 目标 | 备注 |
|------|:----:|------|------|
| I2S BCLK | IO18 | MAX98357 BCLK | 原 Camera D5，需拔排线 |
| I2S LRC | IO17 | MAX98357 LRC | 原 Camera D6 |
| I2S DIN | IO14 | MAX98357 DIN | — |
| MOS SIG | IO1 | 光耦 MOS 模块 | 加湿器开关 |
| LED DIN | IO16 | WS2812 ×16 | 原 Camera D7 |

> ⚠️ **GPIO19 = USB D−，绝对禁用**。配置为 I2S 会导致 USB 断连、烧录死锁。
> ⚠️ **供电必须隔离**：加湿器走充电宝 → MOS DC+，ESP32 只吃 USB 5V。
> ⚠️ **所有 GND 必须共地**，否则出现底噪或随机复位。
