Three principles, one promise.

纯听觉感知

ES8311 Codec + 滑动平均滤波 + 迟滞区间，只判断"此刻是否适合打扰"。

PRIVACY BY DEFAULT

动态香氛配方

三通道雾化按时间与状态实时混合：清晨松木柑橘，深夜薰衣草苔藓。

AROMA BLENDING

主动退让

识别噪音即刻降音、断香、灯环转暗红；3 秒安静后平滑恢复，拒绝惊扰。

HAL · FALLBACK FIRST

听见噪音的那一刻，它先退。

Calm → Noise → Calming
STATE 01

Calm

平稳守望

深蓝呼吸光效，森林声景轻声播放，香氛按当前时段配方间歇释放。RMS 每帧提取，安静时它几乎不存在。

STATE 02

Noise

毫秒级退让

麦克风检测到突发噪音：声景瞬间归零、香氛通道切断、灯环转防守暗红 —— 全部在一帧内完成，不打扰、不询问。

STATE 03

Calming

3 秒平滑回归

环境重新安静 3 秒后，冷却环走完一圈：声景缓缓浮起，香氛从导通相位重新起雾，一切像什么都没发生过。

Frequently asked

一根 USB-C 线和一个 5V 电源即可让主机运行；香氛模块建议用一只独立充电宝供电（供电隔离是硬件避坑第一条）。精油使用常见的松木、柑橘、薰衣草单方精油，滴入对应雾化通道即可。

不会。音频在芯片内部被实时转换成 RMS 能量特征，原始音频流不经过任何存储或网络传输 —— 数据不出设备，也没有云端。它只回答一个问题："此刻是否适合打扰"。

不需要。上电即运行完整的状态机与香氛调度。如果你想调配方、改阈值或加场景，网页控制台与嗅觉实验室提供免代码的可视化方式；想深入源码，固件与调度算法在 GitHub 完全开源。

环境重新安静 3 秒后进入平滑恢复：声景音量阻尼渐入，香氛任务从导通相位重新起雾，灯环回到呼吸深蓝。整个过程没有突然的音量或气味跳变。

可以。嗅觉实验室支持三种方式：手动点击精油瓶逐滴调配、拖动 06:00–24:00 时间轴让配方随时间演化、或选择清晨山坡 / 正午密林 / 黄昏暖室 / 深夜安眠四个场景预设。

当前版本按时间轴与状态机工作；配方、阈值与场景都在端侧配置，随固件保存。我们不依赖任何账号体系，也没有需要你填写的资料。

完全开源。硬件接线、引脚分配、避坑清单与香氛时间切片调度全部公开，见 github.com/huang2399/EmberSigh，欢迎审查与复现。
